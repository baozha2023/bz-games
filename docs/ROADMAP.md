# BZ-Games 未来规划文档

> 版本：v2.1.2 → 展望  
> 更新日期：2026-05-25  

---

## 一、规划总览

BZ-Games 作为一款**无服务器本地游戏平台**，2.x 版本已实现了游戏库管理、联机房间、成就统计、游戏市场、Game API Server 等核心基础设施。未来将围绕 **交互体验提升**、**社交与社区**、**开发者生态**、**多端扩展** 四个方向持续演进，计划通过 v2.2 → v2.5 → v3.0 三个大版本逐步落地。

```
v2.1（当前）  ──→  v2.2（交互增强）  ──→  v2.5（社交生态）  ──→  v3.0（多端平台）
```

---

## 二、版本路线图

### 2.1 v2.2 — 交互体验增强

| 序号 | 功能 | 说明 | 优先级 |
|:---:|------|------|:---:|
| 1 | 游戏标签与分类 | 支持用户为游戏添加自定义标签（RPG、射击、休闲等），在游戏库中按标签筛选 | ⭐⭐⭐ |
| 2 | 游戏排序增强 | 在"最近游玩""自定义排序"基础上，增加"按名称""按导入时间""按游玩时长""按最后游玩"等排序方式 | ⭐⭐⭐ |
| 3 | 网格/列表视图切换 | 游戏库新增列表视图（类似 Steam 列表模式），显示更多游戏信息（游玩时长、成就进度），图标模式新增大幅面模式 | ⭐⭐⭐ |
| 4 | 全局搜索 | 导航栏增加全局搜索入口，支持按游戏名称、标签、作者快速定位 | ⭐⭐ |
| 5 | 托盘快捷菜单 | 系统托盘右键菜单增加"最近游玩"列表，可快速启动最近玩过的游戏 | ⭐⭐ |
| 6 | 游戏封面视频自动轮播 | 游戏库首页封面支持自动轮播选中游戏的预览视频（与详情页封面/视频体验对齐） | ⭐ |
| 7 | 自定义窗口标题栏 | 在设置中开放"隐藏原生标题栏"选项，使用平台自绘标题栏（与深色主题视觉统一） | ⭐ |
| 8 | 键盘导航 | 游戏库支持方向键选中、回车启动/进入详情，Esc 返回，F5 刷新游戏库 | ⭐⭐ |
| 9 | 手柄支持 | 接入游戏手柄按键映射，游戏库和房间界面支持手柄操作浏览 | ⭐ |

### 2.2 v2.5 — 社交与社区生态

| 序号 | 功能 | 说明 | 优先级 |
|:---:|------|------|:---:|
| 1 | 好友系统 | 本地好友列表（以 Player ID 识别），支持添加/删除好友、查看好友在线状态、邀请好友加入房间 | ⭐⭐⭐ |
| 2 | 游戏时长统计增强 | 按日/周/月/年维度展示游玩统计图表，支持导出统计报告 | ⭐⭐⭐ |
| 3 | 游戏评价与评分 | 在游戏详情页增加个人评分（1-5星）和文字评价功能，评价数据本地存储 | ⭐⭐ |
| 4 | 游戏备注 | 用户可为每个游戏添加私人备注（文本笔记），方便记录攻略或备忘 | ⭐⭐ |
| 5 | 游玩会话记录 | 自动记录每次启动→关闭为一次"游玩会话"，包含开始/结束时间、时长、启动的版本 | ⭐⭐ |
| 6 | 房间持久化 | 支持保存常用房间地址为"房间书签"，下次一键加入，无需手动输入地址 | ⭐⭐ |
| 7 | 房间语音通话 | 在房间中内建语音通话能力（基于 WebRTC），无需第三方语音工具 | ⭐ |
| 8 | 联机对战历史 | 记录联机对战记录（参与玩家、胜负、游戏时长），支持对战回放数据导出 | ⭐ |
| 9 | 游戏分享 | 导出游戏 + 评价 + 存档为分享包，好友可一键导入 | ⭐ |

### 2.3 v3.0 — 多端平台扩展

| 序号 | 功能 | 说明 | 优先级 |
|:---:|------|------|:---:|
| 1 | Android 客户端 | 开发 Android 版 BZ-Games，与桌面端共享游戏格式规范，支持本地安装与联机（局域网） | ⭐⭐⭐ |
| 2 | Steam Deck 适配 | 针对 Steam Deck（Linux + 手柄）进行专项适配，包括手柄原生导航、触摸屏优化 | ⭐⭐ |
| 3 | 跨平台联机 | 桌面端与 Android 端在同一局域网下可互相发现并加入房间 | ⭐⭐ |
| 4 | BZ-Games 账号系统 | 可选账号注册/登录（非强制），用于云端存档同步和多设备数据漫游 | ⭐⭐ |
| 5 | 云端存档同步 | 登录账号后自动将游戏存档（gamedata.json）同步到云端，多设备无缝切换 | ⭐⭐ |

## 三、专项规划

### 3.1 游戏市场增强

| 功能 | 说明 |
|------|------|
| 市场关注列表 | 在市场中收藏/关注感兴趣的游戏，有新版本时收到通知 |
| 下载队列管理 | 支持同时下载多个游戏，拖拽调整下载优先级，支持限速设置 |
| 断点续传 | 大文件下载支持暂停/恢复和断点续传，避免网络中断导致重新下载 |
| 增量更新 | 已安装游戏检测已安装版本，仅下载差异文件实现增量更新 |
| 市场搜索与筛选 | 按游戏类型、标签、玩家人数、发布时间等维度筛选市场游戏 |
| 本地市场缓存策略优化 | 市场索引支持增量拉取（ETag / If-Modified-Since），减少不必要网络请求 |

### 3.2 开发者工具链

| 功能 | 说明 |
|------|------|
| bz-launcher-sdk（npm 包） | 发布官方 npm 包，封装 Game API Server 的 WebSocket 调用，提供 TypeScript 类型声明 |
| 游戏调试工具 | 内置"开发者模式"：查看 Game API 消息日志、手动发送测试消息、模拟房间事件 |
| 游戏模板项目 | 提供官方游戏模板（Web/Native），含基础联机框架和成就/统计示例代码 |
| 游戏打包工具 | CLI 工具一键校验 game.json + 打包为标准游戏目录结构 + 生成市场发布包 |
| 市场发布工作流 | 规范市场游戏提交/审核/发布流程，支持私有市场源（企业内部/小团体共享） |
| 在线文档站 | 搭建 docs.bzgames.top 开发者文档站，包含 API 参考、教程、最佳实践 |

### 3.3 用户体验细节

| 功能 | 说明 |
|------|------|
| 启动画面自定义 | 支持设置自定义启动画面/GIF |
| 游戏导入拖拽 | 资源管理器拖拽游戏文件夹到窗口直接触发导入 |
| 通知中心增强 | 通知窗口增加"全部已读""分类筛选"功能，通知持久化保留历史 |
| 成就展示墙 | 新增"成就展示墙"视图：按游戏排列已解锁成就，支持截图分享 |
| 主题市场 | 开放主题/皮肤自定义（CSS 变量注入），支持社区共享主题 |
| 音效增强 | 导入游戏/删除游戏/启动游戏/解锁成就等操作增加更多系统音效，音量独立控制 |

### 3.4 底层基础设施

| 功能 | 说明 |
|------|------|
| 性能监控面板 | 主进程内存/CPU 占用仪表盘，游戏进程资源监控，异常进程自动告警 |
| 崩溃诊断报告 | 游戏崩溃时自动收集日志、系统信息，生成诊断报告，方便开发者定位问题 |
| 数据备份与恢复 | 一键备份全部游戏数据（存档+配置+游戏清单）为 ZIP，支持从备份恢复 |
| 数据库迁移 | 从 electron-store JSON 逐步迁移到 SQLite（better-sqlite3），提升大数据量下读写性能 |
| 便携模式 | 支持 USB 便携运行模式：所有数据（含游戏文件）存储在应用目录，即插即用 |
| 多实例隔离 | 支持同时运行多个 BZ-Games 实例，互不干扰（用于联机自测场景） |

## 四、社区运营规划

| 方向 | 说明 |
|------|------|
| 官方游戏收录 | 定期在官方市场源收录优质社区游戏，建立推荐位和分类展示 |
